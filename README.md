# Site E-Commerce PHP

## Description
Projet de site e-commerce développé en PHP/MySQL permettant :
- affichage des produits
- ajout au panier
- gestion du panier
- paiement via Stripe

## Tech Stack
- PHP
- MySQL
- HTML / CSS
- JavaScript
- Stripe API

## Installation
1. Cloner le dépôt
2. Importer le fichier SQL `gestion_magasin.sql`
3. Configurer `config.php`
4. Lancer le serveur local

## Fonctionnalités
- Authentification
- Catalogue produits
- Panier
- Paiement sécurisé Stripe
